## 배경 (Why)

- 260812 상무님 미팅에서 나온 요구가 세 가지였다 — **현재 도메인 유지 · 검색 노출 · 원하는 사이트 스타일**.
- 도메인 유지가 가능한지, 사이트를 넘겨받을 수 있는지가 리뉴얼 방식 자체를 좌우한다. 그래서 기존 유지보수사에 먼저 물었다.
- **회사명 주의** — 現 **아이티포원(itforone.co.kr)**. 「아이티포유」는 사명 변경 전 표기이며 나우하이텍 사이트 하단에만 남아 있다.

## 과정 (How)

### 1. 도메인 — 나우하이텍 소유가 아니었다

| 항목 | 확인 내용 |
| --- | --- |
| 현재 소유 | **아이티포원 명의**, **가비아** 등록 |
| 이전 가능 여부 | 소유권 이전 · 네임서버 변경 **모두 가능** |
| 선행 조건 | 관리 업체(가비아·후이즈·정보넷 등)에 **계정 생성 필요** |
| 부대 비용 | 이전 시 **도메인 1년 연장 필수** — 연장비 33,000원 |

**이전 방법 2가지**

1. **방법 1 (권장)** — 아이티포원에서 **이전 인증코드**를 받아 고객사가 직접 연장비 결제 및 이전
2. 방법 2 (비권장) — 아이티포원 계좌로 33,000원 입금 + **이전받을 계정 ID/PW 전달** → 아이티포원이 대행
   - ⚠️ **계정 비밀번호를 타사에 넘기는 방식이라 보안상 지양.** 방법 1로 간다.

> 상무님이 말씀하신 「현재 도메인 유지」가 **명의부터 가져와야 성립한다**는 것이 이날 확정됐다.

### 2. 호스팅 — 9월 25일이 실질 데드라인

| 항목 | 확인 내용 |
| --- | --- |
| 배포 위치 | **아이티포원 자체 서버** |
| 원본 파일 백업 | **가능** (진행 여부 확정 요청받음) |
| **만료일** | **2026년 9월 25일** — 미연장 처리 여부 확인 요청받음 |

> ⏰ 이 날짜가 **리뉴얼·도메인 이전의 데드라인**이다. 넘기면 현행 사이트가 내려간다.

### 3. 55만원 역제안 (아이티포원 영업 메일)

같은 날 아이티포원이 먼저 리뉴얼을 제안해 왔다.

- 기존 고객 감사 혜택 명목 → **부가세 포함 55만원**
- 내용: 기존 기반 전체 디자인 리뉴얼 / 모바일·PC 반응형 / SEO / AI 검색 대응 / FAQ·구조화 데이터

> ⚠️ **메시지 불일치.** 메일 하단 고객안내사항에는 「디자인 및 기능작업에 대한 저작권은 아이티포원에 있으므로 원본 데이터는 제공되지 않습니다」라고 적혀 있는데, 실무 답변 본문에서는 **백업 가능**이라고 했다. **이 모순은 260817까지도 해소되지 않았다.**

**질문 5가지**

1. 기획(정보 구조·메뉴 구성 재설계·키카피 등) 포함 여부
2. 기존 콘텐츠 개선이 아닌 **신규 콘텐츠 교체** 포함 여부
3. 나우하이텍 측 제안 콘텐츠 반영 가능 여부
4. 작업 기간
5. 리뉴얼 이후 **유지보수 별도 비용** 여부

도메인·호스팅은 「범위 확인 후 진행 방향을 함께 정하며 이어서 회신」으로 정리해 답을 미뤘다. **범위를 모르는 상태에서 도메인 이전을 확정하면 협상 카드를 먼저 내려놓는 셈이기 때문이다.**

### 5. 방향 결정 (내부)

- **아이티포원과 협업하는 방향으로 가닥.** 이유는 이 건을 **잡음 없이 잘 마무리**하는 것이 최우선이라는 판단 — 성공 시 고객사 추가 소개 약속을 확보한 상태다.
- 아이티포원은 해당 사이트를 오래 운영해 환경 이해도가 높고, 안정적 마무리에 유리하다.
- 단, **55만원 실제 범위 검증이 관건.** 범위·성실도가 곧 파트너 신뢰도 판단 기준이 된다.

> ⚠️ **이 판단은 이후 뒤집히지 않았지만, 단독안이 나란히 올라갔다.**
> 260814 회신에서 **유지보수가 현재 계약(연 30만원, 무제한) 그대로 유지**된다는 점과, **원본 데이터 제공 불가** 정책이 재확인되면서 「협업안 하나만 올린다」가 어려워졌다.
