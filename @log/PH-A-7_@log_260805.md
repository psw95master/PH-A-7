## 배경 (Why)

제안서 v1.0(스크립트 27장 / 슬라이드 33장)에 대한 피드백이 두 가지였다.

1. 내용이 길다
2. 스토리텔링이 맞지 않는다

이에 따라 콘텐츠 목차를 새로 구성하고(`about 나우하이텍 → 웹사이트란 → 진단 → 기대효과 → summary → appendix → 견적`), 그 목차에 맞춰 스크립트를 전면 재작성했다.

대상 독자는 **나우하이텍 대표(66년생)**이며, 이해하기 쉬운 사업 용어와 격식 있는 짧은 문장을 원칙으로 삼았다.

### 2. S12 「즉시 조치」 장 삭제 경위

v2.0까지 「보안 인증서 재발급 · 스팸글 삭제를 오늘 처리해 드리겠습니다」는 장이 있었다. 삭제 사유:

1. 당사가 현재 웹사이트를 운영하는 주체가 아님
2. 기존 유지보수 업체와 연락이 닿지 않는 상황
3. 서버 접근 권한이 없어 이행을 약속할 수 없음

해당 항목은 **리뉴얼 범위로 이관**했다. S9 진단 종합에 「부분 수리 불가 · 리뉴얼 범위에서 처리」 문장을 추가하고, S16 견적의 「포함」 항목에 보안 인증서 발급·적용을 넣었다.

### 3. 스크립트의 논리 축 — 질문 → 실패 → 회복

S3에서 「상대가 확인하는 것」으로 **실재 · 실력 · 태도** 세 질문을 제시하고, S9에서 그 셋 모두에 답하지 못하는 상태를 보인 뒤, S10에서 같은 세 축으로 회복을 말한다.

| 축 | S3 (질문) | S9 (실패) | S10 (회복) |
| --- | --- | --- | --- |
| 실재 | 지금도 운영되는 회사인가 | 경고 화면 · 갱신 2010년 | 정상 접속 · 운영 확인 가능 |
| 실력 | 무엇을 만들고 어디에 납품했나 | 회사 정보 0자 | 글자로 확인 · 검색 노출 |
| 태도 | 문의하면 답이 오는가 | 게시판 하나 · 14년 무응답 | 문의 창구 · 전화 연결 |

> **디자인 지시** — 세 줄은 **S3의 세 질문과 같은 순서, 같은 표기**여야 한다. 표기가 어긋나면 연결이 끊긴다.

이 축은 v2.0 최종본(01-1 「상대가 확인하는 세 가지」, 03-1 「지금 / 리뉴얼 후」)까지 그대로 살아남았다.

### 4. 수치 정정 2건 — 둘 다 재현 불가였다

물려받은 근거 수치인데 **측정 과정이 남아 있지 않아** 직접 재측정했다. 260805 실측이 이 프로젝트 모든 수치의 원본이다.

#### ① 검색되는 글자 수 — 97자 → **57자**

기존 표기는 ESL-C-3 진단 v1.0의 「58자(프레임 합산 97자)」.

| 항목 | 값 |
| --- | --- |
| 최상위 페이지 | 화면 조각(프레임) 2개를 불러오는 구조 |
| 조각 1 `music.htm` | **404 — 파일 없음** |
| 조각 2 `main/index.htm` | 실제 화면. 표시 텍스트 **57자** |
| 그 57자 | `[2010-08-26] 나우하이텍 확장이전 했습니다.` (29자) + `[2006-10-18] 홈페이지가 오픈 되었습니다.` (28자) |
| 이미지 개수 | **14개** (원 진단서 12개 → 재확인 14개) |
| 이미지 설명(alt) | **0개** |
| 내부 페이지 제목 | `Untitled Document` — 회사명 없음 |

「97자」는 두 조각의 합산치이나 한 조각이 404를 반환해 **재현되지 않는다.** 발표 중 확인 요청을 받으면 방어할 수 없어 정정했다.

> **표기 원칙** — 숫자를 크게 띄우는 자리에는 **「회사 정보 0자」**를 쓴다. 57자도 회사 설명이 아니라 16년 전 공지 두 줄이기 때문이다.

#### ② 동종 견적 창구 — 「6개사 중 2곳」 → **「7개사 중 6곳」** (사실과 반대)

기존 표기는 ESL-C-7 기재 수치이나 **조사 대상 목록과 URL이 없어 대조 불가**였다. 재조사 결과:

| 업체 | 보안 | 휴대폰 | 문의창구 |
| --- | :-: | :-: | --- |
| 진양유압 | ○ | ○ | ○ 견적문의 전용 |
| HIMC | ○ | ○ | ○ |
| 태광유압 | ○ | ○ | ○ |
| BB하이드롤릭 | ○ | ○ | ○ |
| ISTC | ✕ | ✕ | ○ 견적/발주 전용 |

| 삼익유공압 | ✕ | ✕ | △ 게시판만 |

- **판정 기준** — 「보유」는 이름·전화 안내가 아니라 **실제 `<form>`과 입력칸이 있어 웹에서 바로 보낼 수 있는 경우**만.
- **논리가 뒤집혔다.** 「2곳뿐이니 앞설 수 있다」 → **「6곳이 하고 있는데 우리만 없다」**. 이 제안서는 「경쟁 우위 확보」가 아니라 **「기본을 갖추지 못해 잃고 있다」**는 구조이므로 바뀐 쪽이 맞다.

### 5. 인증서 실측 (S6 근거)

| 항목 | 값 |
| --- | --- |
| 명의 | `jegikorea.com` |
| **적용 대상** | `jegikorea.com`, `www.jegikorea.com` — **나우하이텍 주소 미포함** |
| 발급 | 2022년 9월 16일 (Sectigo) |
| 만료 | 2023년 10월 17일 |
| 브라우저 오류 코드 | `NET::ERR_CERT_COMMON_NAME_INVALID` |

경고 원인이 **두 가지**다. 만료가 하나, 명의 불일치가 하나인데 **브라우저가 지목하는 것은 명의 불일치**다.

추가로, 경고를 통과해도 **403 Forbidden**이 반환된다. 서버가 보안 접속으로 사이트를 제공하지 않는 상태라 **인증서 발급만으로는 해결되지 않으며 서버 설정 작업이 함께 필요**하다.

### 6. 선급 승인 조사 — 이름 승계가 아니라 갱신이 문제

| 구분 | 확인 내용 |
| --- | --- |
| 이름 변경 | GL → **DNV GL** (2013.9 합병) → **DNV** (2021.3 개명) |
| 기존 증서 처리 | 두 번 다 「기존 증서는 그대로 유효」. 갱신 시점에 새 이름으로 재발급 |
| **유효기간** | **3년** — 선급 용접·제조 승인 (AoM / Welding Workshop Approval) |
| 갱신 조건 | 만료 3개월 전 신청 · 공장 심사 재실시 |
| 공개 조회 | **불가** — 선급 제조 승인은 공개 데이터베이스에서 검색되지 않음 |

- **추정** — 웹사이트의 증서는 GL 명의다. GL이 2013년에 소멸했으므로 최소 2013년 이전 발급분이며, 3년 유효기간을 적용하면 **2016년 이전에 만료**되었다.
- **대응** — S2 자격 항목에서 선급 승인을 뒤로 배치하고, 증서 확인 후 표기를 확정한다.
  - 유효 → 「DNV 선급 용접·제조 승인 (○○○○년까지 유효)」 유효기간 병기
  - 만료 → 자격 항목에서 빼고, 리뉴얼 범위에 「인증 현황 정리」 포함

| A2 | 회사 분위기를 확인할 수 있게 됨 | 동상 |

메인 화면 기준 동종 7개사 전부 채용 항목이 없었다. 사실이라면 **채용 페이지 제안 시 유일하게 「앞설 수 있는 지점」**이 된다. 다만 하위 메뉴를 확인하지 못했으므로 그 시점에 **7개사 하위 메뉴까지 재조사**한 뒤 사용한다.

A3(업무 내용)는 사업분야·설비현황으로 대체 가능하므로 이번 제안서에 남긴다.
