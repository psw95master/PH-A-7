## 과정 (How)

### 1. 문서 형식 결정 — 기준 합의형 → 중립 선택형

- 처음에는 **「판단 기준 3개를 먼저 세우고 → A안 추천」** 형식으로 합의했다. 페리가 A안의 수행 당사자라, 추천이 팔이 안으로 굽는 것으로 읽히지 않도록 기준을 먼저 깔자는 취지.
- 260816 페리 댓글로 **판단 기준 페이지와 A안 추천 페이지를 모두 삭제** → 결과적으로 **A·B를 나란히 놓는 중립 선택형**이 됐다. 상무님이 직접 고르는 구조.
- 부작용: 비교표가 「기준 01/02/03」이라 부를 근거가 사라져 라벨을 **「비교 항목」**으로 바꾸고 각 행에 출처를 붙였다.

### 2. 비용 구조 확정

- **구축비 A안 120만원(VAT 별도) / B안 55만원(VAT 포함)** — B안이 싸다는 사실은 숨기지 않고 먼저 인정하고, 대신 운영비에서 뒤집는 구성.
- **연 운영비: A안 23,100원 vs B안 30만원 (13배 차)**
  - 도메인은 **가비아 실비 23,100원, 당사 수익 없이** 나우하이텍이 직접 납부 (페리 지시 — 원가로 진행)
  - 호스팅은 **청구하지 않음.** 문서에는 서비스명을 쓰지 않고 "당사는 서버를 임대하지 않는 방식으로 구축합니다. 발생하지 않는 비용은 청구하지 않습니다"로만 표기
  - 정기 점검·이상 감지 무상, 하자보수는 **오픈 후 1년**
- **핵심 논거: 연 30만원 × 20년 ≒ 600만원.** 그 20년간 사이트는 2010년 이후 갱신 없음.
  - > ⚠️ 처음엔 이 수치로 독립 페이지(01-3)를 만들었으나, 260816 페리 지시로 **삭제하고 견적 페이지의 옅은 빨강 콜아웃으로 이동**. 이유 — 클라이언트 입장에서 비난조로 읽힘. 톤을 낮춰 살렸다.

### 3. 유지보수 모델 — "무상 점검 + 건별 견적"

- 무제한 무상은 기각. **정기 점검·이상 감지는 기한 없이 무상**, 발견된 추가 작업은 **건별 견적 후 나우하이텍이 진행 여부 결정.**
- 아이티포원과 정확히 거울상이 된다 — *돈을 받으면서 찾지 않았다* vs *돈을 받지 않으면서 찾는다.*
- **방문자 리포트 정기 발송은 선택 옵션**으로 분리. 금액은 이번 문서에 쓰지 않음(추후 유료 상품화 예정이라, 무상 범위에 넣으면 나중에 못 뺀다).
- 구축 범위에 **방문자 분석 도구 설치**를 포함시켜 둘 것 — 안 심어두면 나중에 팔 데이터가 없다.

### 4. 호스팅 — GitHub Pages 기각, Cloudflare Pages 채택

- > ⚠️ **GitHub Pages는 쓰지 않는다.** 약관에 "온라인 비즈니스 등 상거래를 주 목적으로 하는 사이트의 무료 호스팅 용도로는 허용되지 않는다"는 조항이 있다. 회사 소개 사이트는 회색지대이나, 20년 방치를 지적하며 시작한 프로젝트가 약관 문제로 내려가면 신뢰가 끝난다.
- **Cloudflare Pages 채택** — 상업적 이용 제한 조항 없음, 대역폭 무제한, 빌드 월 500회, 파일 20,000개, HTTPS 무료·자동. 서울 노드로 국내 속도도 유리.
- 테스트/라이브 분리는 **Cloudflare Pages 하나로 해결**한다. 깃허브를 테스트용으로 따로 켤 필요 없음.
  - `main` 브랜치 → 라이브(실제 도메인), 작업 브랜치 → `<브랜치>.<프로젝트>.pages.dev` 프리뷰 자동 생성
  - 프리뷰에는 `X-Robots-Tag: noindex`가 **기본 적용**되어 검색 색인 안 됨. Cloudflare Access로 비밀번호도 가능
- **저장소·도메인 명의는 반드시 나우하이텍.** 페리 명의로 두면 "웹사이트가 나우하이텍 자산이 되는가" 논거를 스스로 위반한다.
- 정적 배포라 서버 게시판이 불가 → **문의 창구는 외부 폼 서비스 연동**으로 확정.

## 다음 세션 참고사항

### 작업 방식 — 수정 지시는 슬라이드 댓글로

- 페리가 **파일 댓글로 수정 지시**를 남긴다 (260816 확정). Drive API `comments().list()`로 읽고, `replies().create()`로 답글만 단다.
- 🔴 **해결(resolve) 처리는 하지 않는다.** 페리가 결과를 보고 직접 닫는다.
- `fields`를 안 주면 본문이 안 온다. `anchor`는 슬라이드 번호가 아니라 **객체 ID**라 `presentations().get()`으로 대조해야 한다.
- 자세한 내용은 로컬 메모리 `03. reference/reference_slides_comments_as_feedback.md`.

### 버전 규칙 (260815 확정)

```
{제목}_v{메이저}.{마이너}.{편집}_{완료일}
```

- 편집할 때마다 뒷자리를 올린다. 최종 확정 시 뒷자리를 뗀다.
- **날짜는 완료일**이라 편집해도 갱신하지 않는다. `260818`은 상무님 전달 예정일.
- **레이아웃·정렬 같은 표시 수정은 버전을 올리지 않는다.** 내용이 바뀔 때만.

### 슬라이드 제작 방법 (Slides API)

- 도구는 `~/apps/gdocs/`. `auth.py`의 SCOPES에 `presentations`가 없어도 **`drive` 스코프 덕에 Slides API가 통과한다.** 재인증 불필요.
- 🔴 **함정 1** — `presentations().create()`로 새로 만들면 페이지가 10×5.625in이라 13.333×7.5in 좌표가 통째로 잘린다. Slides API는 페이지 크기 변경을 지원하지 않는다. **기존 덱을 복사하거나 기존 파일 안에서 슬라이드만 교체할 것.**
- 🔴 **함정 2** — `objectId`는 5자 이상, 파일 내에서 유일해야 한다. 재실행 시 겹치므로 타임스탬프를 섞는다.
- 🔴 **함정 3** — 빈 문자열에 `updateTextStyle`을 걸면 400. 텍스트 헬퍼에 빈 값 가드 필요.
- 🔴 **함정 4** — batchUpdate가 중간에 실패하면 슬라이드가 반쯤 들어간 채로 남는다. 재실행 전에 기존 슬라이드를 먼저 전부 지울 것 (단, 0장이 되면 오류라 마지막 1장은 남겼다가 끝에 삭제).
- **검수는 `presentations().pages().getThumbnail()`로 PNG를 받아 눈으로 본다.** 텍스트 넘침은 좌표 계산만으로 안 잡힌다. 특히 **각주가 3줄을 넘으면 화면 밖으로 나간다** — 이번에 4번 반복해서 걸렸다.
- ⚠️ 생성 스크립트 `build_v3.py`는 **세션 스크래치패드에 있어 휘발된다.** 이어서 작업하려면 위 규격 표를 보고 다시 짜거나, 슬라이드를 직접 편집할 것.

### 남은 확인 사항 (※확인 필요)

1. **원본 파일을 실제로 받을 수 있는가** — 아이티포원 메일 내 모순. A안 인수인계가 여기 걸림
2. **B안으로 가도 도메인 명의를 넘겨주는가** — 거래 지속 시에도 응할지 미확인. 응하지 않으면 B안에서 "나우하이텍 자산" 항목이 성립 안 됨
3. **가비아 도메인 이관 소요일** — 8.19 완료 목표에 영향
