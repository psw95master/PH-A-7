# 나우하이텍 홈페이지 — 이미지 텍스트 HTML 전환본

**목적** — nawoohitech.co.kr 의 본문 글자가 JPG/GIF 안에 구워져 있던 것을 전부 실제 HTML 텍스트로 옮긴 정적 사이트.
**전제** — 원본은 2006년식 frameset + 테이블 레이아웃, EUC-KR. 콘텐츠 기준일은 원본에 남아 있던 2010년 8월.
**제약** — 백엔드 없음. 원본의 PHP 게시판(공지사항·Q&A)과 다음 지도 위젯은 정적 페이지로 대체.
**미확정 이슈** — 아래 `※확인 필요` 목록 참조.

작성일 260817.

---

## 1. 실행 방법

```
cd nawoohitech-html
python3 -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8080/index.html`.

HTML 을 고칠 때는 `.html` 파일을 직접 건드리지 말고 `build.py` 를 고친 뒤 다시 생성한다.

```
python3 build.py
```

머리말·꼬리말·좌측 메뉴가 14개 페이지에 반복되기 때문에, 한 곳만 고치면 전부 반영되도록 생성 방식으로 만들었다.
CSS(`assets/css/style.css`)와 JS(`assets/js/nav.js`)는 생성 대상이 아니므로 직접 수정한다.

## 3. 이미지 → HTML 로 바꾼 것

원본에서 **글자가 그림이던 곳**은 전부 텍스트가 됐다. 이제 복사·검색·번역·화면낭독기 모두 된다.

1. **상단 메뉴** `menu.gif` + 이미지맵 → `<nav>` + 링크. 데스크톱은 드롭다운, 모바일은 햄버거 전체메뉴.
2. **좌측 서브메뉴** `left_m1~4.jpg` + 이미지맵 → `<ul>` 목록. 모바일에서는 가로 스크롤 칩으로 바뀐다.
3. **페이지 제목** `t1~t9.gif` → `<h1>` / `<h2>`.
4. **꼬리말** `footer.gif` + 이미지맵 → 주소·사업자번호·연락처 `<dl>` 과 링크.
5. **고객센터** `left_call.gif`, `call.gif` → 전화·팩스·이메일 텍스트. 전화는 `tel:`, 메일은 `mailto:` 로 연결.
6. **메인 배너** `main_img_swf.jpg` → 사진에서 글자 없는 아래쪽 띠만 잘라 배경으로 쓰고, 헤드라인과 4개 태그(선박설비/유압 시스템/산업기계/특수유압 실린더 제작)는 HTML.
7. **메인 카드 4종** `company.gif` `envir.gif` `certi.gif` `equip.gif` → 카드 컴포넌트.
8. **인사말** `contents1.jpg` → 본문 전문 + 대표 사진만 잘라 유지.
9. **조직도** `contents2.jpg` → CSS 로 다시 그린 조직도. 그림 파일 안 씀.
10. **연혁** `contents3.jpg` → 연도별 타임라인 마크업.
11. **오시는길** `contents6.jpg` → 주소·전화·팩스 표.
12. **제품 캡션** `contents7_01.jpg` → 사진 14장을 잘라내고 캡션 14개를 HTML 로.
13. **품질방침 / 환경방침** `contents8.jpg` `contents9.jpg` → 방침 전문, 직무 4개 항, 환경방침 7개 항 전부 텍스트.
14. **도면 캡션·PDF 버튼** `domyun_img.jpg` → 도면 7장 분리 + 모델명/압력 사양 텍스트 + 실제 PDF 링크 버튼.

## 4. 이미지로 남긴 것

**사진과 스캔 문서는 글자가 아니라 자료 그 자체**라서 이미지로 뒀다. 대신 전부 `alt` 를 달고 캡션을 HTML 로 붙였다.

1. 대표 사진 1장, 공장 설비 사진 13장, 제품 사진 14장
2. 인증서 스캔 10장 (ISO 9001/14001, Germanischer Lloyd, KIC)
3. 도면 이미지 7장 — 원본 PDF(`assets/pdf/1~7.pdf`)도 함께 받아 뒀다

인증서 스캔의 글자를 HTML 로 옮겨 적는 안은 **버렸다.** 인증서는 발행기관이 만든 문서이고, 이를 텍스트로 다시 쓰면
원본에 없는 내용이 섞였는지 확인할 방법이 없다. 대신 판독되는 인증번호·기관·범위만 캡션에 적었다. (260817 판단)

## 5. 원본과 달라진 부분

1. **frameset 제거** — 원본은 `music.htm`(0% 높이) + 본문 프레임 구조였다. `music.htm` 은 현재 서버에서 404 라 걷어냈다.
2. **문자셋** EUC-KR → UTF-8.
3. **반응형** — 원본은 1000px 고정. 모바일 우선으로 다시 짜고 데스크톱을 파생시켰다.
4. **다음 지도 위젯 제거** — 외부 스크립트(`dmaps.daum.net`) 의존이라 정적 사이트에서 빼고, 카카오맵 검색 링크로 대체.
5. **게시판** — 공지사항은 등록돼 있던 2건을 그대로 옮겼고, Q&A 는 빈 상태 화면 + 문의처 안내로 대체.
6. **404 페이지 추가** — 원본에 없었다.
7. **오타 정정 2건**
   - 메인 배너 카드 "최고의 기술려으로" → "기술력으로"
   - 조직도 "특수 공기압 실린더 실린더" → "특수 공기압 실린더"
   - 인사말의 "8년이라는 짧은 연력"은 **고치지 않고 원문 유지**했다. 대표 명의의 글이라 임의로 손대지 않았다.

## 6. ※확인 필요

1. **주소 표기가 두 가지다.** 꼬리말은 "부산광역시 강서구 녹산동 화전산단 3로 102", 오시는길 본문은
   "부산광역시 강서구 화전산단 삼로 102". 어느 쪽이 정본인지.
2. **연혁이 2009년 12월에서 끊긴다.** 2010년 이후 이력을 추가할지.
3. **인증서 유효기간** — 스캔 해상도가 낮아 날짜를 읽을 수 없어 비워 뒀다. ISO 9001:2015 / 14001:2015 인증서가
   함께 걸려 있는데, 품질방침 본문은 아직 "ISO 9001 : 2000" 기준으로 쓰여 있다. 방침문을 갱신할지.
4. **도면 5·6번 모델명** — 썸네일로는 판독 불가. PDF 원본을 열어 확인 필요.
5. **설비 사진 13장의 장비명** — 원본에 캡션이 없어 가공장비 현황표와 대조해 붙였다. 실제 장비와 맞는지 확인 필요.
6. **지도** — 어떤 지도 서비스를 쓸지 정해지면 API 키 발급 후 `location.html` 의 `.map-frame` 자리에 넣으면 된다.
7. **Q&A 게시판** — 원본에 15건이 있었으나 외부 스팸으로 보여 옮기지 않았다. 실제 문의글 이전 여부.
8. **폰트** — Pretendard 를 1순위로 지정했으나 파일을 동봉하지 않아, 설치돼 있지 않으면 시스템 고딕으로 표시된다.
   웹폰트로 넣을지.
9. **로고 원본 파일** — 현행 사이트에는 로고가 상단 메뉴 이미지(`menu.gif`) 안에 202×53 크기로만 들어 있어
   거기서 잘라 썼다. 이 크기로는 고해상도 화면에서 흐려지고 확대도 못 한다. **원본(AI·EPS 등) 확보 필요.**

## 7. 컴포넌트와 상태

코드 인계를 전제로, 같은 역할에는 같은 이름을 썼다.

| 컴포넌트 | 클래스 | 상태 |
|---|---|---|
| 주 메뉴 링크 | `.gnb__link` | default / hover / focus-visible / current(`aria-current="page"`) |
| 모바일 메뉴 | `.gnb` + `.nav-toggle` | default / is-open |
| 좌측 메뉴 링크 | `.lnb__list a` | default / hover / current |
| 카드 | `.card` | default / hover(링크일 때만 부상) |
| 버튼 | `.btn`, `.btn--ghost`, `.btn-pdf` | default / hover / focus-visible |
| 갤러리 타일 | `.tile` | default (정적) |
| 표 | `.data-table` | 행 hover |
| 빈 상태 | `.empty` | Q&A 목록 없음 |
| 주석 상자 | `.note` | 판단·미확정 사항 표기용 |

인터랙션은 전부 페이지 이동이다. 상단 메뉴 대분류를 누르면 그 분류의 첫 화면으로 간다
(예: 사업분야 → `products.html`). 모바일 햄버거는 전체 메뉴를 덮어 띄우고, `Esc` 또는 재클릭으로 닫는다.

디자인 토큰(색·폰트·간격·모서리)은 `style.css` 상단 `:root` 에 모여 있다. 색은 원본 이미지에서 뽑았다 —
남색 `#2f2e6e`(로고), 초록 `#4d8f13`~`#94c34b`(서브메뉴 그라디언트).
