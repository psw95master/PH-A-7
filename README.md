제안서(ESL-C-10) S13 「리뉴얼 시안」 삽입용 메인 화면 시안입니다.
제작일 2026년 8월 6일.

| 파일 | 내용 |
| --- | --- |

## 보는 방법

레포를 내려받은 뒤 `1an.html` 또는 `2an.html`을 브라우저로 열면 됩니다.

```bash
git clone git@github.com:psw95master/ESL-A-11-ESL-B-24-ESL-C-12.git
cd ESL-A-11-ESL-B-24-ESL-C-12
open 1an.html
```

**빠르게 확인만 할 때는 `shots/` 안의 캡처 4장을 보면 됩니다.**

### 발표에서 쓰는 법

브라우저에서 연 뒤 **창 가로 폭을 좁혀 보십시오.** 화면이 따라 줄어듭니다.

현행 사이트(`nawoohitech.co.kr`)는 창을 아무리 좁혀도 줄지 않습니다. 두 화면을 나란히 놓고 창을 좁히면 「휴대폰 대응」을 말로 설명할 필요가 없습니다.

---

## 두 안의 차이

세 방향 모두 **속은 전부 새로 만듭니다.** 현행 사이트는 화면 폭이 1200px로 고정된 프레임 구조라 부분 수정으로는 휴대폰 대응이 되지 않습니다.

| 구분 | 1안 기능 개편 | 2안 전면 개편 |
| --- | --- | --- |
| 화면 디자인 | 현행 유지 (초록 계열 · 기존 배치) | 신규 제작 (산업 톤 · 비대칭 구성) |
| 구조 · 코드 | 전면 재구축 | 전면 재구축 |
| 납품실적 | 글자 목록 | 글자 목록 |
| 설비현황 | 설비명 표기 | 설비명 표기 |
| 문의 창구 | 신설 | 신설 |
| 전화 연결 | 휴대폰에서 바로 연결 | 휴대폰에서 바로 연결 |

**두 안의 개선 내용은 동일합니다. 차이는 눈에 보이는 화면뿐입니다.**

## 기술 사항

- 외부 라이브러리 없음. HTML + CSS 단일 파일
- 반응형 기준점 — 1안 900px · 560px / 2안 960px · 600px
- 2안은 스크롤 시 요소가 나타나는 동작 포함. 시스템 「동작 줄이기」 설정 시 자동 해제
- 한글 줄바꿈 처리 적용 (`word-break: keep-all`)
- 폼은 화면 확인용이며 전송 기능은 없습니다
